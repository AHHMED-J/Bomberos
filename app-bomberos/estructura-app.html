Cómo correrlo · en este orden

Todos los comandos se escriben desde la carpeta del repo (Bomberos/). La Mac y el iPhone deben estar en la misma red Wi-Fi.

Una sola vez
  1. 0
    Preparar la IA y el servidor cd app-bomberos/ia-local && ./configurar.sh cd ../servidor && npm install

    configurar.sh crea servidor/.env con una clave al azar y el modo IA local. La clave no se muestra y nunca va al repo. npm install descarga las librerías del servidor.

Atajo · todo de una vez
  1. ⚡
    Un solo comando iPhone por cable, desbloqueado y en la misma Wi-Fi cd app-bomberos/ia-local && ./correr-app.sh

    Hace los pasos 1 a 4 solo: enciende las IAs y el servidor, detecta la IP e instala la app con la clave. Instala la versión release, que se abre desde el inicio del iPhone sin la Mac conectada (sin la pantalla negra de depuración). Al terminar, paso 5.

Cada vez que vayan a probar · a mano
  1. 1
    Encender las dos IAs Terminal 1 cd app-bomberos/ia-local && ./iniciar.sh

    Arranca Whisper (voz → texto) y carga qwen2.5 en Ollama (llenado y resumen). Tarda unos segundos. Ollama debe estar abierto.

  2. 2
    Encender el servidor Terminal 1 · se queda abierta cd ../servidor && npm start

    Es el puente entre el iPhone y las IAs (puerto 3100). Deja esta terminal abierta: si la cierras, la app ya no llega a la IA.

  3. 3
    Saber la IP de la Mac Terminal 2 ipconfig getifaddr en0

    Da algo como 192.168.1.20. Es la dirección que usará el iPhone en el siguiente paso.

  4. 4
    Instalar y abrir la app en el iPhone Terminal 2 cd app-bomberos/movil flutter run --release \ --dart-define=IA=servidor \ --dart-define=SERVIDOR_URL=http://IP-DEL-PASO-3:3100 \ --dart-define-from-file=../servidor/.env

    Con el iPhone conectado por cable y desbloqueado. IA=servidor usa la IA de verdad (sin esto la app usa respuestas de ejemplo). SERVIDOR_URL le dice dónde está la Mac. --dart-define-from-file toma la clave directo del .env, sin copiarla ni mostrarla. La primera vez que toques «Dictar», iOS pide permiso para el micrófono.

Al terminar
  1. 5
    Apagar todo Terminal 1 Ctrl + C cd ../ia-local && ./detener.sh

    Ctrl + C apaga el servidor. detener.sh apaga Whisper y saca qwen2.5 de la memoria (libera unos 12 GB de RAM).

Opcional · revisar que nada se rompió
  1. ✓
    Correr las pruebas cd app-bomberos/movil && flutter test cd ../servidor && npm test

    No necesitan la IA encendida ni el iPhone. Deben terminar en «All tests passed» y «fail 0».
